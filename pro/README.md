# VFX UI Pro

Pro provides complete landing page project source. Collection 01 includes Agency, Marketing, Playful, SaaS and Startup; the initial solo offer is $59 once, with 12 months of updates to this fixed collection and permanent use of delivered versions.

Free components and previously published source remain MIT licensed. The three historical examples in this public directory remain available; they are not the five new private commercial projects.

The new implementation lives in the private `vfx-ui-pro` repository. The public site contains product descriptions and compiled previews; private source ZIPs are delivered through authenticated purchase entitlements. Checkout stays disabled until the complete release and service configuration are ready.

Product decisions and current implementation status are maintained in [ChatGPT Space](https://chatgpt.com/space/page_862f723fd8b88191bddedfc3f84d5cb9). Public product information is at [Pro templates](https://vfx-ui.com/templates/).
