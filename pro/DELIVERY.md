# Pro delivery

The former private-registry / Worker / KV proposal has been superseded.

Collection 01 uses the private `vfx-ui-pro` repository: one Next.js Node application with Better Auth, PostgreSQL and Drizzle. Creem checkout is created server-side for a fixed SKU. Verified payment events grant collection entitlements. Private R2 archives are released as immutable versions, with authenticated download checks and five-minute signed links.

Templates run independently after delivery. Installed websites have no runtime license callback. Free registry installation requires no account.

See the [current architecture and implementation status](https://chatgpt.com/space/page_862f723fd8b88191bddedfc3f84d5cb9). This document does not imply that a live store is available.
