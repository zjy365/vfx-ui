# Pro template thumbnails

This directory contains public template thumbnails only.
It is excluded from the repository's MIT source license; see LICENSE.txt.

The editable Next.js template projects and downloadable archives live in the
separate local `vfx-ui-pro` directory. Public builds use the checked-in
thumbnails and require no access to paid source.

The obsolete static concept demonstrations have been removed. Full application
previews require a separately hosted Node runtime and are not published here.
