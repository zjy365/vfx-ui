# Pro template previews

This directory contains compiled browser demonstrations and preview images only.
It is excluded from the repository's MIT source license; see LICENSE.txt.

The editable Next.js template projects and downloadable archives live in the
private `vfx-ui-pro` repository. Refresh a reviewed release with
`node scripts/sync-pro-previews.mjs /absolute/path/to/private/artifacts`.
Public builds use these checked-in files and require no private repository access.

Browser code can be inspected. These previews demonstrate the product and do not
provide a private-source delivery mechanism.
