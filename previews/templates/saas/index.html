A few useful answers

Before you begin.

Is the event stream connected to a backend?+

No. The inspector demonstrates searching, selecting and pausing a stream of sample events. Connect your own event API and access controls before using it with real data.

Can I inspect an individual event?+

Select a sample row to read its payload and trace identifier. The interface keeps the event stream visible so the individual record stays in context.

What needs to be defined before a real launch?+

Set the ingestion API, identity and permission model, retention policy, service limits and billing. The marketing template does not provide an observability service.
