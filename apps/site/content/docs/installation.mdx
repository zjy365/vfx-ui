Start with an existing React project. React 18 and React 19 are verified. You only need **one** of the installation methods below; neither requires a VFX UI account or API key.

## Option A: copy editable source

The registry copies component source and its shared files into your project, so you can edit them directly.

If your project is not configured for shadcn, initialize it first:

```bash
npx shadcn@latest init
```

Then add Hero Contour, or use the install command on any component's detail page:

```bash
npx shadcn@latest add https://vfx-ui.com/r/hero-contour.json
```

With the default `@/components` alias, the component is available at:

```tsx
import { HeroContour } from "@/components/HeroContour";
```

Your `components.json` configuration determines the destination. If your alias is different, update the import to match. Review the files and dependencies added by the CLI before committing them.

## Option B: install the React package

Use the package when you want to import components without copying their source into your project.

```bash
npm install @vfx-ui/react
```

For DOM and SVG components, import from `/dom`. This entry keeps GPU modules out of the import graph:

```tsx
import { HeroContour } from "@vfx-ui/react/dom";
```

GPU components use the main package entry or their component subpath. Copy the import shown on the component's detail page.

## Add it to a page

This package example renders a complete hero. Replace the copy with your own:

```tsx title="components/LandingHero.tsx"
"use client";

import { HeroContour } from "@vfx-ui/react/dom";

export function LandingHero() {
  return (
    <HeroContour
      title="Find your own way."
      subtitle="A new perspective for your next project."
      interactive
    />
  );
}
```

If you chose editable source, replace that import with the local import from Option A. In a regular React application, render `<LandingHero />` inside your app.

### Using Next.js

Keep the interactive component in a file with `"use client"` at the top, as above. Import it into your page:

```tsx title="app/page.tsx"
import { LandingHero } from "@/components/LandingHero";

export default function Page() {
  return <LandingHero />;
}
```

The page can remain a Server Component. Keep server-side data fetching there and pass serializable props into the interactive component.

## If something does not appear

- **Import cannot be found:** check whether you installed source or the package, then use the matching import. For source installs, check the alias in `components.json`.
- **A background is blank or collapsed:** give its container an explicit height. Backgrounds and canvases need space to render; complete hero components provide their own layout.
- **Next.js reports a client component error:** put `"use client"` at the top of the wrapper that uses the interactive component.
- **A GPU effect is unavailable:** check the component's rendering requirements and test a static fallback on that device.

Next, review [compatibility and accessibility](/docs/accessibility/). For a component's props, return to its page in the [library](/components/).
