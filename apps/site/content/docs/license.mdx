## Free components

The open source VFX UI component library uses the [MIT license](https://github.com/zjy365/vfx-ui/blob/main/LICENSE). Previously published MIT source remains available under that license.

## Commercial use and modification

You may use and modify the free component source in personal, commercial and client projects under the MIT license. Installing source does not require an account or a paid license.

## Redistributing source

Retain the applicable copyright and license notices when redistributing source. Adapted open-source components keep their upstream notices and licenses; review those included with the files you install.

The software is supplied with the warranty disclaimer in the MIT license. This page is an overview; read the full license text linked above.
