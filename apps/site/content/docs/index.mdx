VFX UI is a library of editable React components: heroes, footers, backgrounds, interactions and page sections. The free library uses the MIT license and does not require an account.

## 1. Choose a component

[Browse the component library](/components/) and open a component you like. Its page has a live preview, settings, installation instructions and a usage example.

For a first project, try [Hero Contour](/heroes/hero-contour/). It uses SVG and works without WebGPU.

Choose a section for the page you are building:

- [React hero sections](/heroes/) for the opening headline and call to action.
- [Animated React backgrounds](/backgrounds/) for gradients, particles and shader effects.
- [React footer components](/footers/) for navigation and closing content.
- [Landing page blocks](/blocks/) for features, pricing, testimonials and contact sections.
- [Interactive cards and hover effects](/interactions/) for pointer feedback.
- [Animated text](/text/) and [glass effects](/glass/) for smaller visual details.

## 2. Add it to your project

Copy the component into your project with the shadcn registry. You can edit the source directly, and no account is required.

[Follow the installation guide](/docs/installation/) for the command and a complete example.

## 3. Make it yours

Replace the example text and links, then adjust the component's props to fit your page. The component detail page is the reference for its props and examples.

Before publishing, check the layout on a narrow screen, navigate with a keyboard and test reduced motion. GPU effects also need a fallback for unsupported devices.
