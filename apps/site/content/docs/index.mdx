VFX UI gives you editable components for the parts of a website people remember. Start with a shader, a header, a hero or a footer, then make it your own.

## Choose your starting point

- [Browse the free library](/components/): MIT licensed components for personal and commercial projects.
- [Install a component](/docs/installation/): copy source with the shadcn registry or use the React package.
- [Explore Pro](/templates/): five complete landing page projects, sold as one collection.

## Built for real browsers

The library includes DOM, CSS, SVG and WebGPU effects. Each component page identifies its rendering approach. WebGPU requires a compatible browser and device; keep a useful fallback and test your target environment.

The documentation starts live previews only when you request them. Browsing the library does not create a GPU canvas for every component.
